# 叩君芯会员站 · 无限世界 brief

**用户与主任务**  
会员站访客要走进文游，不是挑选商品。首屏必须能完成三件事：登录、试玩、进入作品。路径仍是登录 → 绑定 → 作品 → 我的解锁。

**目标感受**  
站在主世界门口。副本是可以踏进去的地方，版图会随解锁变大。冷静、可读、有方向，不要货架，也不要后台模板。

**核心隐喻**  
天空即地面。奶油色纸页是从地图上撕下的副本说明书，钉在天空里。橙色只标「你现在该走的那一步」和「唯一的主按钮」。

**构图与层级**  
1. 顶栏路径（登录 / 绑定 / 作品 / 我的解锁）加一枚可见的试玩入口。  
2. 左侧地名：主世界 · 无限世界。一句说明 + 一颗橙色主按钮。  
3. 右侧两张不等大的纸页：分手结局修改器（含试玩）偏前、偏大；梦女小手机偏后、偏窄。  
禁止四宫格作品墙、均分卡片、居中三列卖点。

**色彩与字体**  
天空蓝 `#1387C0` 约占六成（地面、顶栏、页脚）。奶油 `#FAEDD1` 约占三成（可读纸页）。橙 `#F4520D` 约占一成（当前步骤下划线、唯一实心主按钮）。标题用 Newsreader / 思源宋，正文 Figtree / 黑体，坐标与角标用 Spline Mono。

**关键交互**  
主按钮随账号状态指向注册、绑定或作品。试玩链到分手结局的作品入口，不嵌原网页、不进手机屏幕。登录方式切换、解锁确认等表单控件用 Radix 无样式基础件，皮肤跟本 brief。管理台仍是 Element Plus。文游手机内界面不套这套构图。

**避免**  
幻灯片构图、后台皮肤组件库、平均色块、橙色装饰、把手机界面当主页摆件、iframe 旧 HTML 游戏、编造用户数或奖项。

**第一版范围**  
只做会员站外壳：主页这一屏，以及登录 / 注册 / 个人主页账号区 / 作品列表外壳与之同属一个世界。不改文游画面、工具模块、管理台，也不改管理员与会员的登录分流。
