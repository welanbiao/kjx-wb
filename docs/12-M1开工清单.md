### 6.3 🚦 并发验收（最关键，不过不许上线）

> **对应最易出生产事故的解锁原子性。**

```javascript
// k6 脚本：50 并发对同一作品解锁 200 次
export const options = { vus: 50, iterations: 200 };
export default function () {
  http.post(`${__ENV.BASE}/app/works/1/unlock`,
    JSON.stringify({}),
    { headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${__ENV.TOKEN}`,
      'X-Idempotency-Key': `k6-${__VU}-${__ITER}`
    } });
}
```

**验收 SQL（必须全部满足）**：
```sql
-- ① 绝不超解锁
SELECT unlocked_count, available_count FROM kjx_member WHERE id = 1;
-- unlocked_count <= available_count

-- ② 权益数 = 已解锁数
SELECT COUNT(*) FROM kjx_member_entitlement WHERE member_id = 1;
-- 必须 = unlocked_count

-- ③ 解锁记录无重复成功
SELECT work_id, COUNT(*) FROM kjx_unlock_record
 WHERE member_id = 1 AND result = 'SUCCESS' GROUP BY work_id HAVING COUNT(*) > 1;
-- 空结果
```

**再跑一轮**：把 `available_count` 设为 10，用 50 并发打 200 次 → **成功数必须恰好 = 10**。
