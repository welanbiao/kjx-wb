# 接入文游时的常见问题

这份记录只收跨作品都会碰到的问题。某一款的剧情、人名、节点编号不写在这里。

主代理在每个接入开发任务或浏览器测试任务结束时，把新的通用问题补进对应小节。已有条目只补充做法，不另起重复标题。WP-G 写正式接入指南时，以这里已经验证过的条目为准。

## 下次接入先核对

1. 新的数据库脚本版本号必须大于这台库当前的 Flyway 版本。小于当前版本的脚本不会再执行，作品不会出现在会员站列表里。
2. 作品在接入任务里直接写成已上架。不走上架审查。管理员之后可以改成下架。
3. 手机内界面复用原网页的结构和样式。主世界外壳的配色不涂进手机屏幕。
4. 原页面里自己请求模型、自己改钱包、自己写入浏览器存档的脚本删掉，改成后端工具和会话表。新版本若是单文件，页面编号和旧 html 不同，接入前按新文件重数页面，不要沿用旧路径。
5. 密钥只由登录后的用户在页面填写。不写进源码、环境文件、迁移和日志。
6. 数据库验收用本机 `kjx-mysql`（`127.0.0.1:3306`，库 `koujunxin`）和 `kjx-redis`（`127.0.0.1:6380`）。不要为验收再开临时库。80 端口的网关不是数据库。

## 数据与上架

- 接入脚本如果用了已经过去的版本号，现有库会跳过它。补救是新增一条更大的版本号，内容幂等：作品已存在则不再插入。只改模块源码再 `spring-boot:run`，本地 Maven 仓库里的旧 jar 不会带上新的 Flyway 脚本；先对该模块 `mvn -DskipTests install`，再重启 `kjx-server`。
- 作品标题变成问号，是写入库时字符集不对。连接参数使用 `UTF-8`，不要写成 `utf8mb4`。
- 购买成功后，作品详情仍显示未解锁，说明权益写入和详情读取不是同一条判断。购买来源要算作已有权益，购买成功后详情要重新读取，不能停在旧的未解锁标记上。
- 正式开局若被拒绝，页面不得改开试玩局。试玩不调模型；正式局失败要把原因显示在页面上。发送或改写若在几十毫秒内返回且聊天没有新回复，先查会话是不是试玩，以及这次有没有把账号里已保存的地址和密钥交给模型。

## 密钥与模型

- 平台密钥留空时，模型服务这个 Bean 不会创建，完整版发送会立刻返回「完整版需要模型通道」。用户自己的地址和密钥已经保存也没用。用户密钥通道必须在没有平台密钥时仍然存在，并且失败文字要出现在手机页面上，不能只留在接口响应里。改完这条自动配置后，正在运行的后端进程不会自己换上新类，必须重启。账号里的地址和密钥若只放在进程内存，重启后要在账号页再保存一次。
- 页面里另有一套手机内的地址和密钥输入时，不能只提交那一套。账号与安全里已保存的配置，在手机内输入为空时也要被后端用上。
- 发送或改写若在几十毫秒内返回，并且聊天没有新回复，说明没有调用模型。先查这次请求的类型，以及会话是不是被悄悄收成了试玩。
- 完整版会话创建失败时，不要自动改开试玩会话。试玩不扣额度、不调模型；完整版失败应把原因显示出来。

## 界面复用

- 试玩和已解锁游玩共用同一个手机页面。试玩只是会话标记，不另做一套界面。
- 旧顶栏（世界切换和分手概率）只出现在原版允许的屏幕，并且要插到该屏标题下面，不能盖住状态栏。主屏、结局册、标题页不显示这颗按钮。主屏的世界切换只留在底部圆钮。
- 聊天要沿用原版气泡行：日期分隔、左右气泡、时间。不要把记录画成居中纯文字。
- 案卷墙头像、壁纸是空白，和主屏缺图标是同一类问题：签名资源表没有这些文件，页面仍用 `assets/...` 相对路径。左右头像、壁纸、主屏图标、唱片封面、主屏背景音乐都要进同一份签名表。
- 游戏页必须还能回到会员站的作品和主世界。手机画面不能把站点导航盖死。
- 改写如果依赖浏览器弹出的输入框，自动点击走不到。原版能用的发送按钮必须自己把正文交给后端。
- vendor 壳去脚本后，消息列表、气泡、朋友圈、钱包必须按原版 `render*` 的 HTML 形状输出；绑定层只挂事件和调 actions，不要用站点组件替换手机内 DOM。
- 壳只挂载一次：用 `set-screen` 切换 `active` / `has-tab` / `#wechatTabBar.is-on`，不要每次会话刷新整页 `innerHTML`，否则会丢掉节点和监听。
- 检测到服务器存档、继续、新开、重置应做成跨作品通用组件，读 `listSessions` / 会话 reset，文案按作品配置，不要各写一套本地 localStorage 门闩。
- 用户自己上传的音乐：只在浏览器 IndexedDB/本机缓存播放，不写会员库、不走上传接口。会话里最多留「正在播放」元数据；音频二进制永远不进数据库。播放控件可复用分手结局那种 `HTMLAudioElement` 路径。

## 启动

- 在后端父工程上执行启动会因没有主类失败。启动入口是 `kjx-server` 模块。
- 8080 已有进程时，新进程起不来。先确认旧进程是否就是当前后端，再决定停掉哪一个。
- 同一会员站目录不能同时开两个 Next 开发服务。后一次会被拒绝，继续用已经打开的地址。
